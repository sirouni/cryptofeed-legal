プライバシーポリシー

施行日 2026年8月7日 · 製品: 暗号相場（iOS）

本ポリシーは、暗号相場が公開市場の気配、ローカル設定、ピクチャ・イン・ピクチャに関する情報をどう扱うかを説明します。アプリを使うことは、以下の実務を理解したことを意味します。同意しない場合は使用を止めてください。

収集するもの

暗号相場はアカウントを提供せず、個人データを販売しません。設定は端末に残ります。気配の表示は、公開市場データ提供者への通常のネットワーク要求になります。

この製品が使わないシステム権限

このバージョンは天気、GPS、カレンダー、リマインダー、Apple Music／Now Playing を使わず、位置情報、カレンダー、リマインダー、メディアライブラリの許可も求めません。

ネットワークと市場データ

気配がオンのとき、端末は公開市場 API を要求します。提供者は通常、IP アドレスと標準的な HTTP メタデータを見ます。インターネットから何かを取る普通のコストであり、このアプリによる別売ではありません。気配は表示専用です。投資助言ではありません。

ピクチャ・イン・ピクチャに表示されるもの

選んだ気配はシステムのピクチャ・イン・ピクチャに描画されます。その画面を見られる人は気配も見られます。アプリはそれを暗号相場のサーバーへアップロードしません。このバージョンにそのようなバックエンドはありません。

Dynamic Island、Live Activity、ウィジェットに表示されるもの

Dynamic Island、Live Activity、ホーム／ロック画面ウィジェットは、すでに端末上にある同じ最終価格を描画します。追加データを収集せず、暗号相場のサーバーへもアップロードしません。

無音オーディオとバックグラウンド

ピクチャ・イン・ピクチャが開いているあいだ、アプリは無音のオーディオセッションを開始し、窓が背面でも更新できるようにします。聞こえる音は再生せず、音声も収集しません。セッションはゼロ音量バッファ付きの UIBackgroundModes: audio を使います。ピクチャ・イン・ピクチャを生かすためだけに存在し、音楽プレーヤーではなく、追跡にも使いません。

分析と追跡

このバージョンに第三者の広告・追跡 SDK は含まれず、アプリを横断してあなたを追跡するためにもデータを使いません。

情報の使い方

  • アプリを動かすため: 気配を表示し、ピクチャ・イン・ピクチャへ投映する
  • 使わないこと: 広告ターゲティング、データ仲介、個人データの販売、投資助言

保持

  • 設定は端末に残ります（例: UserDefaults）
  • アプリを削除すると、通常それらの設定も消えます
  • 第三者の気配サービスは、各自の方針でリクエストログを保持します

子ども

このアプリは13歳未満の子ども向けではありません。

あなたの選択

  • いつでもピクチャ・イン・ピクチャを閉じたり、関連フローを離れたりできます
  • いつでもアプリの使用を止められます

連絡先

プライバシーに関する質問: GitHub Issues、sirouni@gmail.com、またはアプリ内の About → サポート。

変更

本ポリシーを更新することがあります。重要な変更では施行日を更新し、可能な場合はアプリまたはサポート経路で知らせます。継続利用は更新後のポリシーへの同意を意味します。
