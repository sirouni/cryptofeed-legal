暗号相場

サポート

暗号相場は公開市場の気配を iOS のピクチャ・イン・ピクチャに投映します。表示のみで、投資助言ではありません。

投映（Cast）の手順

  1. アプリを開き、ウォッチリストから通貨を選びます。
  2. 「PiPに送る」をタップします。
  3. アプリを離れます。価格はシステムのピクチャ・イン・ピクチャとして、次に使う画面の上に残ります。

投映に失敗したら、端末がピクチャ・イン・ピクチャに対応しているか確認して再試行してください。一部のシミュレータでは動きません。

1通貨の投映は無料

1通貨のピクチャ・イン・ピクチャ投映は永久無料で、いつでも切り替えられます。浮かぶ窓は課金壁の後ろにありません。任意の $9.99 アンロックは一回払い（サブスクリプションではありません）で、ウォッチリスト最大8通貨、窓内の副次相場最大3つ、価格アラートが加わります。アンロックは「広告なし」ではありません。広告はどちらでもなく、アカウントもありません。

無音オーディオを使う理由

iOS はアクティブなオーディオセッションがあるアプリに対してピクチャ・イン・ピクチャのフレーム更新を維持します。暗号相場は無音・ゼロ音量のバッファを再生し、セッションを開いたままにするだけです。聞こえる音は再生せず、録音もしません。

Dynamic Island、Live Activity、ウィジェット

Dynamic Island、ロック画面の Live Activity、ホーム／ロック画面のウィジェットは、アプリと同じ最終価格を表示します。アプリまたはピクチャ・イン・ピクチャの稼働中に更新され、両方が止まると凍結します。秒刻みのティッカーではなく、アンロックの後ろにもありません。ほぼリアルタイムの面はピクチャ・イン・ピクチャです。

価格の出所

Binance の公開市場データ（読み取りのみ）です。気配は表示専用で、投資助言ではありません。取引、ウォレット、貼り付ける API キー、紹介リンクはありません。

使わない権限

暗号相場は位置情報、カレンダー、リマインダー、Apple Music／メディアライブラリを使いません。それらの許可も求めません。

価格アラート

価格アラートは、この端末上のローカル通知です。Apple Push Notification service（APNs）では届きません。アラートは一回購入の一部です。
