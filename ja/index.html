よくある質問

本物のピクチャ・イン・ピクチャですか、それとも独自の重ね合わせですか？

動画アプリと同じ、本物のシステム機能です。だからアプリを離れても窓が残り、画面上の何にでも重ねられます。

なぜバックグラウンドオーディオを宣言するのですか？

iOS はアクティブなオーディオセッションがあるアプリに対してピクチャ・イン・ピクチャのフレーム更新を維持します。暗号相場は無音・ゼロ音量のバッファを再生し、セッションを開いたままにするだけです。聞こえる音は再生せず、録音もしません。

価格はどこから来ますか？

Binance の公開市場データ（読み取りのみ）です。取引もウォレットもなく、貼り付ける API キーも、アプリ内の紹介リンクもありません。

どんなデータを集めますか？

あなたを特定できるデータはありません。アカウントも追跡もありません。唯一の計測は匿名の利用レポート1件（最初の1週間にピクチャ・イン・ピクチャを使ったか）で、あなたとは紐づきません。ウォッチリストと設定は端末内に残ります。詳しくは プライバシーポリシー をご覧ください。

Dynamic Island やホーム画面ウィジェットに対応していますか？

はい。Dynamic Island、ロック画面の Live Activity、ホーム／ロック画面のウィジェットは、アプリと同じ最終価格を表示します。アプリまたはピクチャ・イン・ピクチャの稼働中に更新され、両方が止まると凍結します。秒刻みのティッカーではなく、アンロックの後ろにもありません。ほぼリアルタイムの面はピクチャ・イン・ピクチャです。

暗号相場は公開市場の気配を一目見るためのものです。投資助言ではありません。取引、保管、紹介はありません。
