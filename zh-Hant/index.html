常見問題

這是真正的子母畫面，還是自訂浮層？

是系統子母畫面，和影片 App 用的是同一個能力。所以離開應用後視窗還在，並能蓋在任何界面上面。

為什麼要宣告背景音訊？

iOS 只會為持有音訊工作階段的 App 持續更新子母畫面。加密行情播放一段靜音、零音量緩衝，只為把工作階段保持住。不會播放任何可聽內容，也不會錄音。

價格從哪裡來？

只讀 Binance 公開市場資料。沒有交易、沒有錢包、不用貼上 API Key，應用內也沒有任何推薦回饋連結。

你們收集什麼資料？

沒有能識別你的資料。無帳號、無分析 SDK、無追蹤。自選和偏好留在本機。完整說明見 隱私權政策。

支援動態島或主畫面小工具嗎？

支援。動態島、鎖定畫面即時動態，以及主畫面／鎖定畫面小工具，展示與 App 相同的最近一筆報價。它們在 App 或子母畫面運行時更新；兩者都停止後，這些表面會凍結——不是秒級行情，也不鎖在付費牆後。接近即時的表面是子母畫面。

加密行情只展示公開市場行情，供快速瞄一眼盤面。不構成投資建議，也不提供交易、保管或任何推薦回饋。
